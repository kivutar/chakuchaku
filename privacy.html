ChakuChaku Privacy Policy

Effective date: August 19, 2026

What ChakuChaku stores

ChakuChaku stores your study progress, answer history, SRS state, and display preferences on your device. ChakuChaku has no user accounts, advertising, or analytics, and the developer does not receive this data.

Progress backups

When you export a progress backup, you choose where to save or share the JSON file. Import only reads the file you select. Backups contain study progress and preferences; they do not contain an OpenAI API key.

Optional AI autocorrection

AI autocorrection is off by default. If you enable it and provide your own OpenAI API key, ChakuChaku sends your answer and the relevant exercise context directly to OpenAI for assessment. The key is kept only for the current app or browser session and is not included in backups. Requests disable response storage and API data is not used for model training by default, but OpenAI may retain abuse-monitoring logs containing prompts and responses for up to 30 days. OpenAI processes this content under the privacy and security protections of its API terms and does not receive it for advertising or tracking. Review OpenAI's API data controls before enabling the feature.

Notifications and audio

On mobile, ChakuChaku asks for notification permission only if you enable the optional daily review reminder. The reminder is scheduled locally on your device. Lesson audio is bundled with the mobile app and cached on demand by the web app.

Data deletion

Use Settings → Reset learning progress to delete local SRS data and answer history. Uninstalling the mobile app or clearing this site's browser data also removes locally stored data. Turning off AI autocorrection stops future transfers. Any request about content already processed by OpenAI must be made through the controls for the OpenAI organization that owns the API key.

Contact

For privacy questions, open an issue in the ChakuChaku repository.

Politique de confidentialité de ChakuChaku

Date d’entrée en vigueur : 19 août 2026

Données stockées par ChakuChaku

ChakuChaku stocke votre progression, votre historique de réponses, l’état du SRS et vos préférences d’affichage sur votre appareil. ChakuChaku ne possède ni comptes utilisateurs, ni publicité, ni outil d’analyse, et le développeur ne reçoit pas ces données.

Sauvegardes de progression

Lorsque vous exportez une sauvegarde, vous choisissez où enregistrer ou partager le fichier JSON. L’importation lit uniquement le fichier que vous sélectionnez. Les sauvegardes contiennent la progression et les préférences, mais jamais votre clé API OpenAI.

Correction facultative par IA

La correction par IA est désactivée par défaut. Si vous l’activez et fournissez votre propre clé API OpenAI, ChakuChaku envoie directement à OpenAI votre réponse et le contexte de l’exercice concerné. La clé est conservée uniquement pendant la session en cours et n’est pas incluse dans les sauvegardes. Les requêtes désactivent le stockage des réponses et les données de l’API ne servent pas à entraîner les modèles par défaut. OpenAI peut toutefois conserver jusqu’à 30 jours des journaux de surveillance des abus contenant les requêtes et réponses. OpenAI traite ces données selon les protections de ses conditions d’utilisation de l’API et ne les reçoit pas à des fins publicitaires ou de suivi. Consultez les règles de gestion des données de l’API OpenAI avant d’activer cette fonction.

Notifications et audio

Sur mobile, ChakuChaku demande l’autorisation d’envoyer des notifications uniquement si vous activez le rappel quotidien facultatif. Ce rappel est programmé localement sur votre appareil. L’audio des leçons est inclus dans l’application mobile et mis en cache à la demande dans l’application web.

Suppression des données

Utilisez Réglages → Réinitialiser la progression pour supprimer les données SRS et l’historique local. Désinstaller l’application ou effacer les données du site supprime également ces données. Désactiver la correction par IA empêche tout nouvel envoi. Toute demande concernant du contenu déjà traité par OpenAI doit être effectuée avec les outils de l’organisation OpenAI propriétaire de la clé API.

Contact

Pour toute question relative à la confidentialité, ouvrez un ticket dans le dépôt ChakuChaku.
